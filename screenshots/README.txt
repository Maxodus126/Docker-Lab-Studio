Bukti visual aktual sebaiknya diambil setelah proyek dijalankan di Windows dengan Docker Desktop.
Gunakan Win + Shift + S untuk menangkap:
1. Dashboard ringkasan saat Flask dan MySQL sehat.
2. Test Center setelah tes dijalankan, termasuk PASS/FAIL/SKIPPED.
3. Aplikasi daftar mahasiswa dengan data uji.
4. Output terminal untuk down/up dan persistensi volume.
Jangan memakai screenshot contoh sebagai bukti hasil runtime.
